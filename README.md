# Automobile Store Business Data Analysis

## Overview
This project presents an end-to-end business data analysis of an automobile store using MS Excel. The objective is to analyze structured sales and customer transaction data to identify trends, understand performance, and support business decision-making.

## Problem Statement
Automobile stores generate large volumes of transactional data, but without proper analysis it is difficult to identify top-performing products, seasonal trends, and slow-moving inventory. This project focuses on transforming raw business data into meaningful insights using Excel.

## Tools Used
- MS Excel
  - Data cleaning and validation
  - Pivot tables and formulas
  - Charts and summary reports

## Analysis Process
- Cleaned data by handling missing values, removing duplicates, and standardizing categories
- Analyzed monthly sales trends and category-wise performance using pivot tables
- Created summary tables and charts for reporting insights

## Key Insights
- Identified peak sales periods and top-selling product categories
- Highlighted slow-moving inventory items
- Provided insights to support inventory planning and sales strategy

## Outcome
This project demonstrates the complete data analytics lifecycle using Excel, from raw data preparation to insight generation and reporting.
